# 周度期权筛选（weekly option screen）

## 这是什么
为**本周五到期**的美股周期权，按“买权利金波段”口径，筛出 call / put 候选。用户**不等到期、不等变实值，赚钱就卖**。

## 用户口径（2026-10-19 确认 ✓，不得自行更改 ✗）

| 项 | 值 |
| --- | --- |
| 预算 | **$15–40 / 张**（$25 为主力档） |
| 到期 | **默认本周五**；用户指定则按指定日期 |
| 方向 | **call + put 都出** |
| 玩法 | 买权利金波段：**赚了就跑**，不等变实值、不等到期 |
| 偏好 | **深虚 + 流动性好**（价差小、有量） |

## IB Gateway 连接与取数硬规则（全是踩过的坑 ✓✓）

1. 连 `127.0.0.1:7497`，**clientId 26/27/28**；**绝不用 42**（QQQ 实盘系统占用 ✓）。
2. **同一时刻 ≤20 张合约**，取完立刻 `cancelMktData`。一次要上百张 ⇒ IBKR **静默限流** ⇒ 卡在**不可中断的 socket 读**上（连 `signal.alarm` 都打不断 ✗）。
3. `reqSecDefOptParams` 必须用 `qualifyContracts` 拿到的**真实 conId**；**传 0 会挂死** ✗。
4. 每次 `ib.sleep(6~10)`；取不到**就跳过**；同批最多重试 2 次，**不要死等** ✗。
5. 连不上 ⇒ **报“数据不可用”，禁止编造任何价格/行权价** ✗✗。握手超时 ⇒ **换 clientId 重试一次** ✓。
6. **15:45–16:00 ET 不取数**（价差翻倍，实测 AAPL 365C 到 81% ✗）。
7. 取数前先看 QQQ watcher 是否正常（`~/workSpace/qqq-0dte-watcher/logs/<YYYYMMDD>.jsonl` 里有 `market_snapshot` ✓）；查询**不能干扰它** ✓。
8. 任何结论前**先看原始 bid/ask/量/OI** ✓（防 σ/单位算错）。

## 三个核心指标（怎么读表）

- **弹性** = `|delta| × 现价 ÷ 权利金` ⇒ 标的动 1% 权利金动几 %
- **回本需动** = `买卖价差% ÷ 弹性` ⇒ **真实摩擦**：<0.2% 优秀 ✓｜>0.5% 别做 ✗
- **隐含周幅** = `ATM 跨式 ÷ 现价` ⇒ 市场认为会不会大动

## 选标的经验（数据结论 ✓）

- **深虚玩法下，价差最紧的大盘股（NVDA/PLTR/TSLA/META/TQQQ）明显优于小票** ✓（价差 1–5% vs 8–22% ✗）。
- 预算 $15–40：想**靠近现价** ⇒ 选 **$10–50 的中低价高波动股**；想**深虚** ⇒ 选**大盘股** ✓。
- **赌大盘方向首选 TQQQ**（3 倍杠杆 ✓，call/put 都是 3 倍弹性 ✓）。

## 交付格式（固定）

1. 到期日 + 剩余天数（写清楚）
2. call 候选表 + put 候选表（按“回本需动”升序）
3. 每方向**首选 3 张** + 一句话理由
4. **排除清单**（回本需动 >0.5% 的，说明为什么别做 ✗）
5. **关键价位**：用 QQQ 前日高低 / 5 日高低给止盈线与失效线
6. 操作提醒：限价单 / 尾盘不交易 / 到期全损
7. 结尾「以上为数据分析，非投资建议」✓

## 必须对用户说的诚实边界 ✗

- **这不是套利**：方向性虚值周权波段，**期望 ≈ −价差（负）** ✗；只有方向判断有优势才可能盈利。
- **+50% 就跑 = 主动加税** ✗（实测期望 −20% vs 不设止盈 −2.5% ✓）⇒ 止盈宜宽。
- **周五收盘前买 = 白交 3 天 theta** ✗（实测同一张 SOFI 15C：周五 $0.20 → 周一 $0.13 ✓）⇒ 周一/周二买。
- 深虚周权**大概率归零** ✓ ⇒ 强调只用能全损的钱。

## 常见故障处置

| 现象 | 处置 |
| --- | --- |
| 连接超时 | 换 clientId 重试 1 次 ✓ |
| `Error 200 / 无 security definition` | 该行权价不存在 ⇒ 跳过 ✓ |
| 报价全 NaN | 可能未开盘/已收盘 ⇒ 提示盘中重跑 ✓ |
| 某标的无该到期 | 跳过并记录 ✓（如 AMD、GOOGL 无周五周期权） |
| 结果异常（弹性 >200 或回本 <0.02%） | 核对原始报价；大概率 σ 反解用了跨式而未 ÷2 ✗ |
